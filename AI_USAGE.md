# AI Usage

## AI tool used

Project work was assisted by GitHub Copilot in Visual Studio Code, accessed through the Copilot SDK. No other AI tools are claimed here.

## Assistance provided

AI assistance was used for:

- Exploring the existing React components, hooks, task model, storage behavior, and CSS structure before making changes.
- Planning and implementing parts of the dashboard, task workflows, calendar, settings, themes, profile, and responsive presentation.
- Debugging issues and suggesting code improvements, including validation, accessibility, and responsive behavior.
- Running and interpreting project checks such as the production build and lint command, and performing browser-based UI checks during implementation.
- Preparing and reviewing project documentation.

AI suggestions and generated code are not a substitute for project review. The feature descriptions in the README are based on the current implementation; no backend, authentication, or cloud synchronization is implied.

## Developer review and responsibility

The developer remains responsible for reviewing and understanding all project code, validating behavior on their target devices, checking the final repository contents, and deciding what to submit or deploy. The developer is also responsible for protecting personal data and for independently verifying any AI-assisted changes.
